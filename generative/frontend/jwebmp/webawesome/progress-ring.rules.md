# WaProgressRing — WebAwesome (JWebMP Wrapper)

Wrapper for `wa-progress-ring`. Aligns with ../../webawesome/progress-ring.rules.md.

Usage
- Configure value/max, size/stroke, label, and indeterminate mode via fluent setters; place in clusters/stacks.
- Prefer for radial progress; not a layout primitive.

Patterns
- Maintain CRTP chaining; provide aria attributes per base rules.
