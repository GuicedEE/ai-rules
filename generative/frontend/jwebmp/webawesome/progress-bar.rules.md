# WaProgressBar — WebAwesome (JWebMP Wrapper)

Wrapper for `wa-progress-bar`. Mirrors ../../webawesome/progress-bar.rules.md.

Usage
- Add to clusters/stacks; set value/max, indeterminate, label, and appearance via fluent setters.
- Use for linear progress; do not overload as a layout element.

Patterns
- Keep CRTP chaining; provide accessible labels/states.
