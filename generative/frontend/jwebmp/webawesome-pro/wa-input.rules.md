## Overview

**WaInput** is a form input component that provides text, email, password, number, and other input types. It integrates WebAwesome's input styling with JWebMP and Angular property binding.

### Purpose
- Provide accessible, styled form input fields
- Support various input types
- Enable reactive form binding in Angular
- Support validation feedback
