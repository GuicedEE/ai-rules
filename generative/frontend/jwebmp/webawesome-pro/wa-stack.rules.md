**WaStack** is a vertical layout container that arranges child elements in a column. It provides flexible spacing, alignment, and responsive support.

### Purpose
- Arrange components vertically with flexible spacing
- Support flex alignment
- Enable responsive layouts
- Maintain consistent spacing
