## Overview

**WaCluster** is a horizontal layout container that arranges child elements in a row. It provides flexible spacing, alignment, and wrapping support.

### Purpose
- Arrange components horizontally with flexible spacing
- Support flex alignment
- Enable responsive wrapping
- Maintain consistent spacing
