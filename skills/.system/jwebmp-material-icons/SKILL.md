# Material Icons

## Overview

Integration of Material Icons into JWebMP with typed component model, CRTP API, dual rendering (HTML/JSON), and page configurators.

```java

// Create component
// Example usage depends on the specific Material Icons library
```

- Integrating with JWebMP Component model
- Server-driven event handling
- Feature-based functionality

```xml
<dependency>
  <groupId>com.jwebmp.plugins</groupId>
  <artifactId>material-icons</artifactId>
</dependency>
```
