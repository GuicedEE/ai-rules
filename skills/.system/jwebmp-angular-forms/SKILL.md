# Angular Forms

## Overview

Integration of Angular Forms into JWebMP with typed component model, CRTP API, dual rendering (HTML/JSON), and page configurators.

## Quick Start

```java
import com.jwebmp.plugins.angularforms.Angular;

// Create component
// Example usage depends on the specific Angular Forms library
```

## Use Cases

- Angular form building, reactive forms, form validation
- Integrating with JWebMP Component model
- Server-driven event handling
- Feature-based functionality

## Installation

```xml
<dependency>
  <groupId>com.jwebmp.plugins</groupId>
  <artifactId>angular-forms</artifactId>
</dependency>
```
