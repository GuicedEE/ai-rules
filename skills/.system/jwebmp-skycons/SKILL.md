# Skycons Weather Icons

## Overview

Integration of Skycons Weather Icons into JWebMP with typed component model, CRTP API, dual rendering (HTML/JSON), and page configurators.

## Quick Start

```java

// Create component
// Example usage depends on the specific Skycons Weather Icons library
```

## Use Cases

- Weather icons, animated SVG icons
- Integrating with JWebMP Component model
- Server-driven event handling
- Feature-based functionality

## Installation

```xml
<dependency>
  <groupId>com.jwebmp.plugins</groupId>
  <artifactId>skycons</artifactId>
</dependency>
```
