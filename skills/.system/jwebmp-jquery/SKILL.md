# jQuery Library

## Overview

Integration of jQuery Library into JWebMP with typed component model, CRTP API, dual rendering (HTML/JSON), and page configurators.

## Quick Start

```java

- Integrating with JWebMP Component model
- Server-driven event handling
- Feature-based functionality

  <artifactId>jquery</artifactId>
</dependency>
```
