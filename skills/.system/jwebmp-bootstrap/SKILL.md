# Bootstrap CSS Framework

## Overview

Integration of Bootstrap CSS Framework into JWebMP with typed component model, CRTP API, dual rendering (HTML/JSON), and page configurators.

## Quick Start

```java
import com.jwebmp.plugins.bootstrap.Bootstrap;

// Create component
// Example usage depends on the specific Bootstrap CSS Framework library
```

## Use Cases

- Bootstrap grid system, responsive layout, Bootstrap components
- Integrating with JWebMP Component model
- Server-driven event handling
- Feature-based functionality

## Installation

```xml
<dependency>
  <groupId>com.jwebmp.plugins</groupId>
  <artifactId>bootstrap</artifactId>
</dependency>
```

Version managed by JWebMP BOM.
