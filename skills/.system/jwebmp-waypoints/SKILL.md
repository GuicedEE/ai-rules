# Waypoints Scroll Plugin

## Overview

Integration of Waypoints Scroll Plugin into JWebMP with typed component model, CRTP API, dual rendering (HTML/JSON), and page configurators.

## Quick Start

```java
import com.jwebmp.plugins.waypoints.Waypoints;

// Create component
// Example usage depends on the specific Waypoints Scroll Plugin library
```

## Use Cases

- Scroll detection, lazy loading, scroll animations
- Integrating with JWebMP Component model
- Server-driven event handling
- Feature-based functionality

## Installation

```xml
<dependency>
  <groupId>com.jwebmp.plugins</groupId>
  <artifactId>waypoints</artifactId>
</dependency>
```
